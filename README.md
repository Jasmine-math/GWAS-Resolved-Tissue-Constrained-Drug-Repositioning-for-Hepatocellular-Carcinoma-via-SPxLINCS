# GWAS-Resolved-Tissue-Constrained-Drug-Repositioning-for-Hepatocellular-Carcinoma-via-SPxLINCS

End‑to‑end, reproducible code for GWAS‑resolved, tissue‑constrained drug‑repositioning in hepatocellular/hepatobiliary cancers. The pipeline integrates GWAS‑imputed transcriptomic signatures via S‑PrediXcan with LINCS L1000 perturbational profiles (SPxLINCS), applies key‑tissue reverse‑signature filtering, aggregates drug‑level evidence, and summarizes results as bipartite/tripartite Cytoscape networks. Clinical plausibility is assessed by Drug‑Set Enrichment Analysis (DrugEnrichr vs SIDER).
